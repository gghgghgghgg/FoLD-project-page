# FoLD Project Page

Official project page for **FoLD: Force-Informed Learning for Dexterous Articulated Object Manipulation**.

This repository contains only the static files required by the website. It can be served directly with GitHub Pages from the repository root.

## Local preview

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Public links

The paper, arXiv entry, source code, and BibTeX citation will be linked when available.
